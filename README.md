# 💰 Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS and JavaScript.

## 🚀 Features

- Add income
- Add expenses
- View current balance
- View total income
- View total expenses
- Delete transactions
- Transaction history
- Data persistence using LocalStorage
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
